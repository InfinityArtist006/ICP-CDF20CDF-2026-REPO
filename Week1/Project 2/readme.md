# API Data Ingestion Pipeline

Simple API ingestion pipeline using Spaceflight News API.

## Features

- Fetch news articles from API
- Pagination handling
- Incremental loading
- Duplicate prevention
- SQLite storage
- CSV export
- Retry on failures
- Logging

## Install

pip install -r requirements.txt

## Run

python main.py

## Output Fields

- Title
- Published Date
- Source
- URL
- Summary
